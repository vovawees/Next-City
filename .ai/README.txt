NEXT-CITY / .ai — KNOWLEDGE BASE FOR AGENTS AND MAINTAINERS
format   dry dense plain text, english identifiers, lines <= 120; no secrets (tokens/keys never here or in git)
rule     refresh after every logical step, in the same commit as the code it describes
state    M0-M7 done (issues #1-#24), docs #25 and this base #26 done; M8 services in progress (status.txt, next.txt)

FILES
  architecture.txt  layers L0-L4, boot, packages, module contract (ctx), event bus, bridge, rounds and modes, city,
                    client, data flow, key decisions D1-D20 (digest of docs/ARCHITECTURE.md)
  api.txt           GENERATED: per module public methods by realm, emits/asks/reduces/listens, console commands;
                    cross refs: question/reduction -> askers and answerers, event -> emitters and listeners
  modules.txt       GENERATED module map (provides/requires/optional/files/net/components) + hand notes under NOTES
  net.txt           net messages and components of every module, schema types, client checks, budgets, rates
  stack.txt         languages, runtime, style, tools, toolchains (agent sandbox, VPS), commands
  testing.txt       runner, GMod emulator (tests/gmod), helpers, specs, counts, bench, lint rules
  vps.txt           VPS host, project folder, tmux sessions, ports, what runs there
  github.txt        repo, auth, commit/push rules, milestones, issues -> commits
  status.txt        milestones and issues done, last full test run, pending checks
  bugs.txt          emulator vs real GMod gaps, pitfalls met while coding and testing
  next.txt          ordered plan

SESSION START (fresh agent)
  1 read README.txt, status.txt, next.txt, architecture.txt; grep api.txt / modules.txt for the module at hand
  2 git clone https://github.com/vovawees/Next-City.git (or git pull); toolchain per stack.txt
  3 luajit tests/run.lua -> "N specs, M passed, 0 failed" (status.txt); glualint lint gamemodes tests lua -> nothing
  4 work per next.txt; contracts: module README.md (russian, API section) + header comments of module files
  5 every step: tests + lint, refresh .ai (status, next, generated maps), no secrets in the diff, commit, push

REGENERATE (after changing manifests or public methods; from the repo root)
  luajit tools/apimap.lua > .ai/api.txt
  { printf 'MODULE MAP (generated by luajit tools/modmap.lua; notes below)\n\n'; luajit tools/modmap.lua; echo;
    sed -n '/^NOTES$/,$p' .ai/modules.txt; } > /tmp/modules.txt && mv /tmp/modules.txt .ai/modules.txt
