NET (platform/net.lua messages, platform/components.lua replication, core/schema.lua codecs; D5: no WriteTable/NW)

NAMES AND BUDGET
  message     own net string "nc.<module>.<name>" (pooled by util.AddNetworkString at define time)
  component   one string per store "nc.<module>:<component>"
  platform    nc.hello (client info + ready, rate 2/burst 4), nc.info (later info changes, 2/8)
  budget      self-limit 256 strings (STRING_BUDGET; engine limit 4096); default boot uses 40 = 23 messages +
              15 components + 2 platform (module example is off; it adds 2 messages + 1 component)

CLIENT -> SERVER CHECKS (cheap first)
  ready (nc.hello received, else drop notReady) -> token bucket per player and message (rate/s, burst; default
  10/20) -> size within schema minBits..maxBits -> parse with validation (NaN/inf, ranges, lengths, enums, valid
  entities) -> handler in xpcall. rate/size/invalid = violations: counted, logged <= 1/s per player, event
  net.violation(ply, message, reason, detail). Drops without a violation: notReady, noHandler, unpooled.
  outgoing checks: config net.checkOutgoing = true validates server sends too (debug).

SCHEMA TYPES (core/schema.lua; fields = list of {name, type, opts})
  bool; uint/int (bits or min/max); float; double; quant(min, max, bits); string(max bytes); enum(values);
  array(of, max); struct(fields); entity; player; vector; angle; normal; color; optional = true (messages only)

COMPONENTS (platform/components.lua)
  fields in schema syntax, <= 31 per component (split if more), no optional fields (use uint 0 = none);
  replicate nil = local store per realm, "all" = every ready player, "owner" = only the owner (key = player);
  rate = flushes per second; changes batched per tick into one message per store, deltas by field mask;
  a player becoming ready (net.ready) gets the full state; client mirror: store:OnChange(fn(index, data, mask)),
  store:Changed(mask, field); keys = entities or entity indexes.
