# Модуль `chat` — чат

Что игрок пишет в чат — строка канала. В роли: сказано вслух, шёпотом, криком, действие персонажа (`/me`) или мир вокруг (`/it`) — слышно вокруг говорящего, где режим делает чат местным (город), и всем — где нет. Вне роли: всем (OOC) или тем, кто рядом (LOOC). Личные сообщения (`/pm`, `/r`) — по именам, которые видят другие. `/<слово>` — команда модуля. Без сознания — только вне роли; правила раунда про мёртвых сохраняются; поток строк сдерживается.

| | |
|---|---|
| Интерфейс | `chat` (оба realm) |
| Зависимости | `players`; необязательные: `notices` (что не так со строкой), `menu` (раздел «Чат» справки F1), `organism` (без сознания), `teams` (командный чат) |
| Слушает | `players.left`; отвечает на `gm.PlayerSay` (`""`: движок ничего не показывает — строки идут сообщением `line`) |
| Спрашивает | `chat.proximity (ply)` → `true`: чат местный, `false`: общий (без ответа — настройка `proximity`); `chat.canSpeak (ply, channel, text)` → `false`: нельзя; `chat.command (ply, word, args, rest)` → `true` (сделано), ответ (строка или строки) или `false` (нельзя); `gm.PlayerCanSeePlayersChat (text, teamOnly, listener, speaker)` → `false`: этот не видит |
| Испускает | `chat.said (ply, channel, text, audience)` (`pm`: `audience = { ply, target }`) |
| Сеть | `line` (сервер → клиент): `channel`, `speaker`, `name` (как его видят другие), `text`, `dead` |
| Команды | `nc_chat` (всем): каналы, радиусы и местный ли чат сейчас |
| Настройки | `proximity` = `false`, `whisperRange` = 100, `sayRange` = 350, `yellRange` = 900, `loocRange` = 350 (юниты: 100 ≈ 2 м), `maxLength` = 200 символов, `rate` = 1 строка/с, `burst` = 5, `repeatDelay` = 2 с, `log` = `true` (строки в консоли сервера) |

## Каналы

| Что набрать | Канал | Кто видит | Строка |
|---|---|---|---|
| `текст` | `say` | вокруг (`sayRange`), где чат местный, иначе все | `Имя: текст` |
| `/w текст` | `whisper` | всегда только вокруг (`whisperRange`) | `Имя шепчет: текст` |
| `/y текст` | `yell` | вокруг (`yellRange`), где чат местный, иначе все | `Имя кричит: текст` |
| `/me открывает дверь` | `me` | как `say` | `* Имя открывает дверь` |
| `/it Дверь скрипит` | `it` | как `say` | `** Дверь скрипит` |
| `// текст`, `/ooc текст` | `ooc` | все | `[OOC] Имя: текст` |
| `.// текст`, `/looc текст` | `looc` | вокруг (`loocRange`) | `[LOOC] Имя: текст` |
| `/pm имя текст` | `pm` | получатель; отправитель видит `[ЛС] → Имя: текст` | `[ЛС] Имя: текст` |
| `/r текст` | `pm` | последний, с кем была переписка | `[ЛС] Имя: текст` |
| командный чат (U) | `team` | своя команда во время командной игры (без неё — как `say`) | `(КОМАНДА) Имя: текст` |
| `/job police` | — | только автор: ответ команды | серые строки |

Имя — `players:Name`: персонаж в городе ([`identity`](../identity/README.md)), псевдоним в Homicide, иначе ник; цвет имени — цвет команды. Теги — на языке игрока; текст проходит фильтр игры `util.FilterText`, как в базовом чате (настройка `cl_chatfilters`). Строки в роли от неживого помечены `*МЁРТВ*`.

## Кто слышит

- **Расстояние** — от говорящего до слушателя, без учёта стен; где чат общий, `say`, `yell`, `me`, `it` слышат все, шёпот и LOOC — всегда только вокруг.
- **Без сознания** (`organism`) не говорят и не слышат в роли — только OOC и LOOC (уведомление «Вы без сознания: только вне роли (// текст)»).
- **Мёртвые** (и наблюдатели) там, где чат местный, говорят в роли только с теми, кто не жив, — на любом расстоянии; где общий — со всеми, с пометкой. Правило раунда `dead_mute` (ответ `gm.PlayerCanSeePlayersChat`) везде скрывает мёртвых от живых.
- Каждый слушатель напоследок проходит `gm.PlayerCanSeePlayersChat` (ответы модулей шины); говорящий всегда видит свою строку. Личное сообщение проходит тот же вопрос для получателя и `chat.canSpeak` с каналом `pm`.

## Антиспам

- Строка очищается (управляющие символы — в пробелы, пробелы по краям — прочь) и не длиннее `maxLength` символов UTF-8 (кириллица считается по буквам).
- Подряд — `burst` строк, дальше — `rate` в секунду (ведро жетонов); та же строка снова — не раньше чем через `repeatDelay` с. Что не прошло, видит только автор — уведомлением.
- Строки модулей (`chat:Send`) идут без антиспама.

## Команды чата

`/<слово> аргументы`: сначала вопрос `chat.command` — модуль отвечает на свои слова; иначе — консольная команда `nc_<слово>` с её привилегией (`/job police` = `nc_job police`, `/rpname Анна Каренина`). Аргументы в кавычках — одно слово: `/pm "Анна Каренина" привет`. Ответ — серыми строками в чате автора (первые 12; все — в консоли, уведомление «Ещё N строк — в консоли (~)»). Неизвестное слово — уведомление «Нет команды /слово», строку не видит никто. Клиентские команды (`nc_fall`, `nc_inventory`) из чата не запускаются.

## API

```lua
local chat = ctx:Require("chat")                 -- в манифесте: optional = { "chat" }
chat:Send(ply, "it", "Вдали воет сирена")        -- строка канала от игрока, без антиспама: true или false, причина
chat:Private(ply, target, "текст")               -- личное сообщение
chat:Info(ply, { "строка", "строка" })           -- строки только для игрока (ответы команд)
chat:Say(ply, text, teamChat)                    -- строка так, как её набрал игрок (антиспам, команды)
chat:Audience(ply, "say", text)                  -- кто получит строку: готовые игроки по индексу
chat:Proximity(ply); chat:Range(ply, "yell")     -- местный ли чат; радиус канала (nil — всем)
chat:Find("алиса", ply)                          -- игрок по видимому имени, или nil и target | many
chat.Parse("/w привет")                          -- "whisper", "привет"
chat.Words('a "b c"')                            -- { "a", "b c" }
chat:Parts(line)                                 -- клиент: цвета и тексты строки для chat.AddText
```

Причины отказа: `empty`, `long`, `spam`, `repeat`, `unconscious`, `denied`, `target` (нет такого), `many` (подходят несколько), `self`, `nobody` (некому ответить), `unknown` (нет команды).

```lua
-- режим делает чат местным (в Setup; раунд снимает ответ сам)
round:On("chat.proximity", function(ply)
	return true
end)

-- модуль отвечает на свои слова
ctx:On("chat.command", function(ply, word, args, rest)
	if word == "roll" then
		return "1d6: " .. math.random(1, 6) -- строка или строки только автору; true — ответа нет
	end
end)
```

## Справка F1

Раздел «Чат — пишется в строке чата (Y)» вкладки «Справка» меню F1 ([`menu`](../menu/README.md)): `/w`, `/y`, `/me`, `/it`, `//`, `.//`, `/pm`, `/r`, `/...` с описаниями на языке игрока.

## Проверить в реальном GMod

- Строки в окне чата: цвета имён по командам, теги, `*МЁРТВ*`, фильтр `util.FilterText` (`cl_chatfilters`), длинные строки и кириллица.
- Командный чат (U) в TDM; в городе — слышно вокруг, крик дальше, шёпот вплотную; мёртвые в Homicide не видны живым.
- ULX и подобные: команды `!` и `ulx gag` работают через хуки `PlayerSay` раньше режима; хуки аддонов `PlayerCanSeePlayersChat` и клиентский `OnPlayerChat` строк модуля не видят — они идут сетью (ответы шины работают).
- Антиспам при быстром наборе, `/pm` по частям имён, `/r` после выхода собеседника.
