# Модуль `movement` — движение по возможностям тела

Тело решает, как игрок двигается (D6): возможности `organism` задают скорости движка, отнимают бег и прыжок, заставляют ползти тело, которое не держат ноги, и оставляют без ввода игрока без сознания. Общий модуль: клиент предсказывает своё движение с теми же ограничениями, что и сервер.

| | |
|---|---|
| Интерфейс | `movement` |
| Зависимости | `players`, `organism` |
| Слушает | `organism.capabilities`, `players.spawned` (после `organism`: базовое появление сбрасывает скорости), `players.died`, `players.left`, `players.stateChanged`, `gm.StartCommand` (сервер и клиент) |
| Настройки | `walk` = 160, `run` = 300, `slowWalk` = 90 (клавиша `+walk`), `crawl` = 45 — юнит/с здорового тела; `crouch` = 0,4 — доля ходьбы вприсядку; `jump` = 190 — сила прыжка |

## Что делает тело

| Состояние | Скорости | Команды игрока |
|---|---|---|
| здоров | из настроек | без изменений |
| стоит | ходьба, бег и медленная ходьба × `moveSpeedMul`; нет бега — бег равен ходьбе; нет прыжка — сила прыжка 0; прыжок × (0,7 + 0,3 · `moveSpeedMul`) | убираются `IN_SPEED` без `canSprint` и `IN_JUMP` без `canJump` |
| не может стоять (`canStand` = `false`) | ползком: `crawl` × 1 с двумя руками, × 0,65 с одной, × 0,3 без рук (`canUseArmL/R`) | присед принудительно, без бега и прыжка |
| без сознания | — | никаких клавиш, кроме приседа, ни движения, ни импульсов (фонарик) |

В noclip ограничений нет. Ограничения общие для сервера и клиента: сервер ставит скорости (движок передаёт их клиенту), команды обрезаются на обеих сторонах, поэтому предсказание сходится с сервером. Игрок без ограничений стоит одного поиска в таблице на команду.

## API

- `M:Limit(ply)` → ограничение (`{ frozen, keep, add }`) или `nil`.
- `M.LimitOf(caps)` → ограничение для возможностей (общая функция).
- Сервер: `M:Speeds(caps)` → ходьба, бег, медленная ходьба, доля приседа, сила прыжка; `M:Apply(ply, caps)` — применить.
