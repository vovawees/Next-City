# Модуль `spectator` — наблюдение

Камеры тех, кто не жив: сначала смерть глазами движка, потом наблюдение за живыми или свободная камера. Кого можно смотреть, решает сервер; клиент только показывает цель и клавиши.

| | |
|---|---|
| Интерфейс | `spectator` |
| Зависимости | `players`; необязательно `teams` (без него ограничения по командам нет) |
| Слушает | `players.stateChanged`, `players.left`, `teams.changed`, `gm.KeyPress` |
| Спрашивает | `spectator.canObserve (viewer, target)` → `false` запрещает следить за целью |
| Испускает | `spectator.target (viewer, target, old)` — сменилась цель (`nil` — свободная камера) |
| Переводы | `lang/<код>/spectator.lua` |
| Настройки | `deathCam` = 3, `camera` = `in_eye`, `teamOnly` = `true` |

## Как это работает

- **Умер** — `deathCam` секунд камера смерти движка, затем наблюдение. **Наблюдатель** (`spectator`) наблюдает сразу.
- **Камеры:** `in_eye` (глазами цели) → `chase` (со стороны) → `roaming` (свободный полёт) → … по прыжку. Атака и альт-атака — следующий и предыдущий игрок по индексу; из свободной камеры атака возвращает к последней цели. Свободная камера начинается в глазах того, за кем следили. Выбранная камера сохраняется между смертями.
- **Кого видно:** живых, кроме себя. С `teamOnly` игрок команды видит только живых товарищей, пока они есть, — потом любого. Наблюдатели вне команд видят всех. Режим или правило может запретить цель через `spectator.canObserve`.
- **Смена цели:** умерла, ушла, сменила команду или стала запрещённой — на следующем тике берётся следующая; если следить не за кем, камера свободная, пока кто-нибудь не появится (сначала — прежняя цель). Дважды в секунду сервер проверяет все камеры, так что цель, которую поменял движок (`spec_next` и т. п.), тоже исправляется.

## API (сервер)

- `M:Observe(ply)` — начать наблюдение сейчас (камера смерти заканчивается раньше).
- `M:IsObserving(ply)`, `M:Target(ply)`, `M:Camera(ply)` — `"in_eye"`, `"chase"`, `"roaming"` или `nil`.
- `M:SetCamera(ply, camera)`, `M:Follow(ply, target)`, `M:Next(ply, 1 | -1)`.
- `M:CanObserve(viewer, target)` — считает живых, не для циклов по всем игрокам.
- `M:Viewers(target)` — кто сейчас смотрит на игрока.

## Клиент

Внизу экрана, пока игрок не жив: «Наблюдение» и имя цели цветом её команды (или «Свободная камера»), обратный отсчёт возрождения из `players.life.respawnAt` и подсказка по клавишам. Цель и камера — из сетевых данных движка; строки пересобираются при изменениях и раз в секунду, а не каждый кадр.

## Проверить в реальном GMod

- Камера смерти движка без `Spectate` и то, что `CheckObserverSettings` не уводит камеру с разрешённой цели другой команды.
- Позиция свободной камеры после `SetPos` в глаза цели.
