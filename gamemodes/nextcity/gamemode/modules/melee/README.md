# Модуль `melee` — ближний бой

База холодного оружия пакетов: ножей, бит, топоров, а также рук. Оружие — это данные: какие у него удары, сколько в них энергии, глубина клинка, дальность, тайминги и сколько сил тратится на замах. Скриптовое оружие на базе `nc_melee` замахивается одинаково на сервере и предсказывающем клиенте. Удар ищет цель с компенсацией лагов, по телам бьёт через конвейер `damage`, по остальному наносит урон движка. Своего оружия в ядре нет (D15).

| | |
|---|---|
| Интерфейс | `melee` |
| Зависимости | `players`, `organism`, `damage` |
| Испускает | `melee.struck (owner, weapon, ent, index)` — сервер, каждый удар, который во что-то попал (`index`: 1 — основной, 2 — второй; `ent` может быть и миром) |
| Команды | `nc_melee` — зарегистрированное оружие и его удары |
| Настройки | `energy` = 1 — множитель энергии ударов; `entityDamage` = 0,1 — урон движка на джоуль по пропам, NPC и стеклу; `push` = 1 — множитель толчка; `lagCompensation` = `true` — удар видит других там, где их видел бьющий |

## Как устроено

1. **Замах.** Клавиша атаки — основной удар, атака 2 — второй; если держать, удар повторяется. Нажатие начинает замах: через `windup` с. наносится удар, ещё через `recovery` с. можно бить снова. Состояние (`Attack`, `StrikeTime`, `Swings`) хранится в предсказываемых NetworkVars, поэтому клиент бьющего видит замах без задержки. Если убрать оружие, замах сбрасывается.
2. **Удар.** Линия из глаз на `reach` юнитов проверяет хитбоксы; если она промахивается, проверяется оболочка замаха (куб со стороной `2·size`). Если оболочка задела тело сбоку, удар направляется в его середину, на хитбокс по пути. На сервере всё это идёт под `LagCompensation`, в команде бьющего.
3. **По телу** (игрок или тело, в котором он лежит): попадание организма `blunt`/`slash`/`stab` через `damage:Inflict` с энергией, глубиной клинка, точкой и хитгруппой. Количество попадания — энергия / 8, как у урона движка. Тупой удар даёт ушибы и переломы, а очень сильный (от `knockdown`·8 Дж, по умолчанию 480) сбивает с ног через `ragdoll`. Клинок оставляет раны на `depth` см, пока не упрётся в кость. Упавшее тело получает толчок, у клинков есть кровь `BloodImpact`.
4. **По остальному.** Пропы, NPC и стекло получают урон движка (`damage` удара или `энергия·entityDamage`, `DMG_CLUB`/`DMG_SLASH`) с толчком. По миру урона нет, только эффект `Impact` и звук.
5. **Тело бьющего** (возможности `organism`). Без сознания или без рабочей руки замахнуться нельзя; если рука отказала во время замаха, удара не будет. Двуручное оружие в одной руке замахивается в 1,5 раза дольше и бьёт с половиной энергии, одноручному одной руки хватает. Каждый замах тратит `stamina` выносливости (`organism:Exert`); без сил удар идёт с 60% энергии, а клинок входит мельче. Удар, который попал, отдаёт в руки толчком камеры.

## API

- `M:Register(class, def)` (обе стороны, в `Init` модуля пакета) — регистрирует или заменяет оружие и делает скриптовое оружие `class` на базе `nc_melee`. Ошибки описания — `melee: Register('<class>'): …`.

| Поле | Что это | По умолчанию |
|---|---|---|
| `primary` | основной удар (обязательно) | — |
| `secondary` | удар клавишей атака 2 | нет |
| `hands` | 1 — одноручное, 2 — двуручное | 2 |
| `draw` | с. на доставание | 0,5 |
| `sounds` | `{ draw }` | — |
| `holdType`, `viewModel`, `worldModel`, `viewModelFOV`, `viewModelFlip`, `useHands`, `slot`, `slotPos`, `weight` | как в движке | `knife` / `melee2` по `hands`, слот 0 |
| `name` | ключ переведённого имени | `melee.<class>` |

Поля удара:

| Поле | Что это | По умолчанию |
|---|---|---|
| `kind` | `blunt`, `slash` или `stab` (обязательно) | — |
| `energy` | Дж полного удара | 60 |
| `depth` | см, на которые входит клинок при полной энергии | `slash` 4, `stab` 12 |
| `reach`, `size` | дальность из глаз и половина стороны оболочки, юниты | 48, 4 |
| `windup`, `recovery` | с. от нажатия до удара и после удара до следующего | 0,15, 0,35 |
| `stamina` | доля выносливости на замах | 0,02 |
| `damage` | урон движка по пропам и NPC | `энергия·entityDamage` |
| `anims` | `{ swing, hit }` — `ACT_VM_*` замаха и попадания | `ACT_VM_MISSCENTER`, — |
| `sounds` | `{ swing, hit, world }` — замах, попадание по телу, по остальному | — |

- `M:Get(class)`, `M:All()`, `M:IsMelee(weapon)`, `M:Name(class)`; `M:Trace(owner, attack)` и `M:Strike(owner, weapon, attack, index, scale)` — для баз поверх `nc_melee` (руки).
- База `nc_melee`: `Def()`, `AttackOf(index)`, `CanSwing(owner)`, `Swing(index)`, `_SwingAnim(attack, index)` — их можно переопределить в своей базе.

```lua
-- Пакет: нож — режет основным ударом, колет вторым.
melee:Register("knife_kitchen", { hands = 1, draw = 0.4, worldModel = "models/weapons/w_knife_t.mdl",
	primary = { kind = "slash", energy = 40, reach = 40, windup = 0.1, recovery = 0.3,
		sounds = { swing = "Weapon_Knife.Slash", hit = "Weapon_Knife.Hit", world = "Weapon_Knife.HitWall" } },
	secondary = { kind = "stab", energy = 60, depth = 12, reach = 36, windup = 0.25, recovery = 0.6 } })
```

## Проверить в реальном GMod

- Нож и бита из пакета: замахи и попадания на сервере с пингом (`net_fakelag`), предсказание анимаций без дрожи.
- Удар сбоку по игроку и по упавшему телу; промах дальше `reach`.
- Пропы ломаются и толкаются; стекло; NPC получают урон; по миру — эффект и звук.
- Сломанная рука: двуручное медленнее и слабее; без сил удары слабее.
