# Модуль `hands` — руки

Пустые руки каждого игрока: скриптовое оружие `nc_hands` на базе `melee`. Опущенные руки переносят и тащат пропы и тела, поднятые становятся кулаками. Это часть тела, а не контент: оружие приходит из пакетов (D15). Если режиму руки не нужны, модуль можно выключить (`modules.disabled.hands`) или не выдавать их (`give = false`).

| | |
|---|---|
| Интерфейс | `hands` |
| Зависимости | `players`, `organism`, `melee` |
| Слушает | `players.loadout` (рано, приоритет 90) — выдаёт руки до снаряжения режима |
| Запросы | `hands.grab (ply, ent)` — `false` запрещает брать (защищённые пропы) |
| Испускает | `hands.grabbed (ply, ent)`, `hands.dropped (ply, ent, thrown)` — сервер |
| Настройки | `give` = `true` — руки каждому вышедшему игроку; `raise` = 0,35 — с. на подъём и опускание кулаков; удар: `energy` = 50 Дж, `reach` = 40 юнитов, `windup` = 0,1, `recovery` = 0,45, `stamina` = 0,03; переноска: `carryReach` = 72 юнита, `strength` = 24000 кг·юнит/с² (около 40 кг против гравитации 600), `carryStamina` = 0,04 выносливости в секунду при полной силе, `throwEnergy` = 150 Дж, `throwSpeed` = 600 юнитов/с; `viewModel` = `models/weapons/c_arms.mdl`; звуки `swingSound`, `hitSound` |

## Как устроено

1. **Опущены и подняты.** После доставания руки опущены: ничего не видно, бить нельзя. Клавиша перезарядки поднимает кулаки и опускает их за `raise` с. (последовательности `fists_draw` / `fists_holster` модели рук, holdtype `fist` / `normal`). Состояние (`Raised`, `RaiseTime`) — предсказываемые NetworkVars, как у базы.
2. **Кулаки.** Клавиша атаки поднятых рук бьёт: это удар базы `melee` (`blunt`, `energy` Дж на `reach` юнитов, с замахом, восстановлением и тратой сил), левой и правой по очереди (`fists_left` / `fists_right`). Если рука не работает, бьёт другая; без обеих рук и без сознания удара нет.
3. **Переноска** (опущенные руки, сервер). Пока зажата атака 2, руки хватают то, что впереди в пределах `carryReach`: физический проп или тело (рэгдолл — за ту физическую кость, в которую попал взгляд). Игроков, NPC, оружие и закреплённые пропы взять нельзя. Взятое тянется туда, где было, перед глазами, но не сильнее `strength` (с одной рукой — половина) и не быстрее 300 юнитов/с. Лёгкое следует за взглядом, тяжёлое волочится, слишком тяжёлое остаётся на месте. Тяга одна на тик физики, сколько бы команд ни пришло от лагающего клиента. Сильная тяга тратит выносливость; без сил тяжёлое выпадает, а лёгкое остаётся в руках.
4. **Выпадает**, если отпустить клавишу, поднять кулаки, лишиться рук, встать на взятое, убрать руки или если взятое дальше 1,25·`carryReach` от глаз (застряло или отстало).
5. **Бросок** — клавиша атаки, пока что-то в руках: энергия `throwEnergy` в массе всего предмета (`E = m·v²/2`, у тела — масса всех костей), не быстрее `throwSpeed`.

## API

- `M:Active(ply)` → руки, если они у игрока в руках; `M:Raised(ply)`; `M:Carried(ply)` → то, что он несёт (сервер).
- `M:Grab(hands)`, `M:Hold(hands)`, `M:Throw(hands)`, `M:Release(hands, thrown)` — сервер, для режимов и тестов.
- Оружие `nc_hands`: `Raise(raised)` — поднять или опустить кулаки (например, режим опускает их по своему правилу).

## Проверить в реальном GMod

- Кулаки: подъём и опускание, анимации `c_arms`, удары по игрокам, предсказание без дрожи; сломанная рука.
- Переноска: лёгкий проп следует за взглядом без рывков, ящик тяжелее 40 кг волочится, тело тащится за кость; бросок.
- Нельзя встать на проп в руках и поднять себя; поведение при лаге (`net_fakelag`).
- `nc_hands` первым в слоте 0; в TDM в руках последнее оружие снаряжения.
