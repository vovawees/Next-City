# Модуль `hud` — минимальный HUD тела

Никаких чисел здоровья и костюма (D6: здоровье движка ничего не значит). Игрок видит своё тело так, как его чувствует: экран темнеет по краям, теряет цвет и плывёт, без сознания — чёрный; короткие строки говорят, что не так с телом и какая броня надета.

| | |
|---|---|
| Интерфейс | `hud` (только клиент) |
| Зависимости | `organism`; необязательно `armor` |
| Слушает | `organism.vitals`, `organism.capabilities`, `armor.changed`, `i18n.changed`, `gm.HUDShouldDraw`, `gm.HUDPaint` (раньше других модулей: их тексты поверх чёрного экрана), `gm.RenderScreenspaceEffects` |
| Настройки | `effects` = `true` — эффекты экрана; `statuses` = 8 — больше строк состояния не показывается |
| Строки | `lang/<код>/hud.lua`: `hud.status.<флаг>` для каждого флага `organism`, `hud.unconscious`, `hud.succumbIn`, `hud.succumb`, `hud.armor`; названия брони — `armor.<id>` |

## Что на экране

| Что | Откуда | Как |
|---|---|---|
| потеря цвета | `vitals.grey` (кровопотеря, гипоксемия) | `DrawColorModify`: насыщенность 1 − 0,95 · grey |
| потемнение, туннельное зрение | `vitals.dark` (мало кислорода мозгу) | яркость и контраст ниже, края экрана темнеют градиентами к центру |
| размытие | `vitals.blur` (сотрясение, гипоксия, опиоиды) | `DrawMotionBlur` |
| без сознания | `caps.unconscious` | чёрный экран, «Без сознания» и когда можно сдаться: «Сдаться можно через N с», затем «R — сдаться» (клавиша `+reload` игрока) |
| состояния | `vitals.status` | слева внизу в порядке флагов `organism` (`STATUS_ORDER`), цвет по тяжести: красный — остановка сердца, сильное кровотечение, удушье, паралич; оранжевый — кровотечение, шок, переломы, вывих, сотрясение, ожоги, отравление, переохлаждение; жёлтый — боль, изнеможение; голубой — жгут, повязка |
| броня | `armor:Worn()` | справа внизу над патронами: «Бронежилет 85%» |

Элементы HL2 `CHudHealth`, `CHudBattery`, `CHudSuitPower`, `CHudDamageIndicator`, `CHudPoisonDamageIndicator` скрыты всегда (`M.HIDDEN`), прицел, патроны, выбор оружия и зум — без сознания (`M.HIDDEN_UNCONSCIOUS`). Тексты пересобираются, только когда меняются флаги, броня или язык (подсказка — когда меняется показанная секунда), а не каждый кадр. Без тела (наблюдатель, мёртв) HUD ничего не рисует.

## API

- `M:Rebuild()` — пересобрать все тексты; `M:RebuildStatuses()`, `M:RebuildArmor()`.
- `M.HIDDEN`, `M.HIDDEN_UNCONSCIOUS`, `M.SEVERITY` — таблицы, которые можно дополнить из другого модуля.
