# Модуль `storage` — постоянные данные

Данные модулей, которые переживают смену карты и перезапуск сервера: банковские счета, владельцы дверей, точки лута. Один JSON-файл на пространство имён в папке `garrysmod/data/nextcity/`.

| | |
|---|---|
| Интерфейс | `storage` (только сервер) |
| Зависимости | — |
| Слушает | `gm.ShutDown` |
| Испускает | `storage.flushed (ns)` |
| Команды | `nc_storage [flush \| <пространство> [ключ]]` (админ) |
| Настройки | `folder` = `"nextcity"`, `flushDelay` = 2 с, `pretty` = `false` |

## API

```lua
local storage = ctx:Require("storage")
local bank = storage:Open("bank")                 -- data/nextcity/bank.json, читается один раз
local key = storage:PlayerKey(ply)                -- SteamID64, для ботов "bot_<имя>"
bank:Set(key, { cash = 500 })
local account = bank:Get(key)
account.cash = account.cash + 100
bank:Touch()                                      -- таблица изменена на месте
bank:Delete(key); bank:Keys(); bank:Count(); bank:Each(); bank:Flush()
```

## Правила

- Имя пространства — строчные буквы, цифры и `_`; ключи — непустые строки.
- Значения — всё, что сохраняет JSON: строки, числа, логические значения, таблицы со строковыми ключами и массивы. Строковые ключи вида `"12"` остаются строками.
- Изменения копятся: файл пишется через `flushDelay` секунд после первого изменения (одной записью), при выключении сервера и при остановке модуля.
- Повреждённый файл копируется в `<пространство>_corrupt.txt`, хранилище начинается пустым, в лог — предупреждение.

## Проверить в реальном GMod

- Время записи больших файлов (тысячи ключей) и отсутствие подвисаний тика.
