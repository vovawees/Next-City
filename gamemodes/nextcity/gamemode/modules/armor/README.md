# Модуль `armor` — бронезащита

Броня — слои в слотах (шлем, жилет, пластины). Слой, закрывающий место попадания, останавливает или замедляет пулю по классу защиты; остановленная пуля всё равно бьёт по телу запреградной травмой, каждое попадание изнашивает броню.

| | |
|---|---|
| Интерфейс | `armor` |
| Зависимости | `players`, `organism`, `damage` |
| Слушает | `players.loadout` (первым: снимает броню — режимы надевают свою), `players.died`, `players.stateChanged`, `players.left` |
| Испускает | `armor.hit (ply, hit, kind, stopped)` — слой встретил попадание (сервер); `armor.changed (pieces)` — броня своего игрока изменилась (клиент) |
| Компоненты | `armor` (владелец, 4 Гц): `pieces` — до 8 слоёв `{ id, condition }`, внешние первыми |
| Команды | `nc_armor [игрок] [вид \| -слот \| strip]` — показать, надеть, снять слот, снять всё |
| Настройки | `bluntScale` = 1 — множитель запреградного удара; `wear` = 1 — множитель износа |
| Строки | `lang/<код>/armor.lua`: названия видов `armor.<id>` и слотов `armor.slot.<слот>` |

## Стадия `armor` (200)

Стадия конвейера `damage` между `localize` и `wound`. Слои, закрывающие область и сторону входа, встречают попадание по порядку слоёв (внешние первыми), каждый — с вероятностью своего `share` (края, стыки).

| Попадание | Что делает слой |
|---|---|
| `bullet`, `fragment` | угроза снаряда против защиты класса (ниже у изношенного слоя). Остановлен — попадание становится `blunt` с долей `blunt` материала от энергии (`hit.stopped`, `hit.absorbed`); пробит — летит дальше с остатком энергии, медленнее и мельче проникает, не разрушается |
| `slash` | останавливает любой слой: лёгкий удар |
| `stab` | останавливают жёсткие слои и классы 3+; мягкий слой ниже пропускает клинок на 40 % глубины |
| `blunt`, `stun`, `crush` | слой распределяет удар: остаётся доля `melee` материала |
| `blast` | осколки взрыва встречают броню по одному (`hit.shield`) — каждый проходит как `fragment` |

Угроза — энергия (Дж) × √(9 / диаметр, мм) × `ap` (бронебойность боеприпаса). Попадание без точки на теле (ближний бой некоторых NPC) считается попаданием в грудь спереди. Износ за попадание — угроза / (защита × `hits`) × `wear`; изношенный слой сохраняет долю `floor` защиты.

## Виды

| Вид | Слот | Класс | Материал | Закрывает | `share` | `hits` | Масса, кг |
|---|---|---|---|---|---|---|---|
| `helmet` | `helmet` | 4 | `hard` | голову | 0,9 | 4 | 1,4 |
| `vest_light` | `vest` | 2 | `soft` | грудь, живот со всех сторон | 1 | 6 | 2 |
| `vest` | `vest` | 4 | `soft` | грудь, живот со всех сторон | 1 | 6 | 3,5 |
| `plates` | `plates` | 5 | `hard` | грудь, живот спереди и сзади | 0,8 | 4 | 6 |
| `plates_heavy` | `plates` | 6 | `hard` | грудь, живот спереди и сзади | 0,8 | 3 | 8 |

Пластины надеваются поверх жилета (слой 1, жилеты — слой 2). Свои виды — `armor:RegisterArmor(id, def)`: `slot`, `class` (1..6), `material`, `coverage` (`{ [область] = true | { [сторона] = true } }`), `share`, `hits`, `layer`, `mass`.

## API

Сервер:

- `M:Equip(ply, id, condition)` — надеть вид `id` (вместо слоя в том же слоте), `condition` 0..1 (по умолчанию 1) → `true` или `false, "unknown" | "dead"`.
- `M:Unequip(ply, slot)` → была ли броня в слоте; `M:Strip(ply)` — снять всё.
- `M:Worn(ply)` → `{ { id, slot, condition }, ... }`, внешние первыми (новая таблица).
- `M:Kind(id)`, `M:Kinds()`, `M.Covers(kind, область, сторона)`, `M.Threat(энергия, снаряд)`.

Клиент: `M:Worn()` → слои своего игрока `{ id, condition }` или `nil`.
