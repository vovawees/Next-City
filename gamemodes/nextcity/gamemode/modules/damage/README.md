# Модуль `damage` — конвейер урона

Урон движка становится попаданиями по телу `organism` (D6): здоровье движка у игроков не меняется никогда. Пуля сохраняет свои дробины, тип боеприпаса и дистанцию; броня и другие модули меняют попадания упорядоченными стадиями.

| | |
|---|---|
| Интерфейс | `damage` |
| Зависимости | `players`, `organism` |
| Слушает | `gm.ScalePlayerDamage` (запись дробин), `gm.EntityTakeDamage` (блокирует весь урон игрокам, кроме `players:Kill`; урон носителя тела — попадания по его игроку), `gm.OnPlayerHitGround` (падения), `players.left` |
| Отвечает | `gm.EntityTakeDamage` → `true`, `gm.GetFallDamage` → `0` |
| Испускает | `damage.hit (ply, hit)` — после всех стадий каждого попадания |
| Спрашивает | `gm.PlayerShouldTakeDamage (ply, attacker)` → `false` — урона нет (правила раунда, огонь по своим); `damage.kind (ply, dmginfo)` → вид травмы вместо вида по типу урона (например, `"stab"` для ножа), `false` — без травмы |
| Команды | `nc_damage [число]` — последние попадания: кто, чем, энергия, дистанция, куда, броня, раны |
| Настройки | `scale` = 1 — множитель энергии пуль; `engineEnergy` = 25 Дж на единицу урона для пуль неизвестного боеприпаса; `falls` = `true`; `fallSpeed` = 300 юнит/с — более медленные приземления не рассматриваются; `punch` = 1, `push` = 1 — множители тряски камеры и толчка; `history` = 32 |

## Как устроено

1. `gm.ScalePlayerDamage` вызывается движком для каждой дробины (и для трассы удара в ближнем бою) — модуль записывает точку, направление, хитгруппу, боеприпас и урон. Слушатель с низким приоритетом: если кто-то заблокировал пулю раньше, она не записывается.
2. `gm.EntityTakeDamage` приходит один раз на сложенный урон (мульти-урон движка). Модуль всегда отвечает `true` — движок здоровье не трогает, — а урон превращает в попадания: пуля — по одному на дробину, остальное — одно попадание. Ошибка в стадии не пропускает урон в движок: она пишется в лог.
3. Ничего не происходит в режиме бога, без живого тела, при уроне 0, от утопления (его модель считает сама) и если `gm.PlayerShouldTakeDamage` ответил `false`.
4. Падения: `gm.GetFallDamage` всегда 0, приземление быстрее `fallSpeed` не в воду — попадание `fall` со скоростью; переломы решает `organism`.
5. Носитель тела. Урон сущности, которая несёт тело игрока (`organism:PlayerOf`, например регдолл упавшего), становится попаданиями по этому игроку, а сам урон идёт дальше в движок — он толкает регдолл (модуль игрока не толкает). `gm.ScalePlayerDamage` для регдолла не вызывается, поэтому дробь приходит одним уроном с точкой последней дробины: число дробин — урон, делённый на наибольший урон одной (`GetMaxDamage`), и все они проходят через эту точку. Скрытого игрока такого тела находит только радиус взрыва — этот урон игнорируется, взрыв получает само тело.

Вид травмы по типу урона (первое совпадение): `DMG_DISSOLVE` → `lethal`; `DMG_DROWN` — нет; `DMG_BLAST` → `blast`; `DMG_BULLET`, `DMG_BUCKSHOT`, `DMG_AIRBOAT`, `DMG_SNIPER` → `bullet`; `DMG_BURN`, `DMG_SLOWBURN`, `DMG_PLASMA`, `DMG_ENERGYBEAM` → `burn`; `DMG_SHOCK` → `shock` (с `DMG_CLUB` — `stun`, шокер); `DMG_SLASH` → `slash`; `DMG_CLUB` → `blunt`; `DMG_VEHICLE` → `vehicle`; `DMG_CRUSH`, `DMG_PHYSGUN` → `crush`; `DMG_FALL` → `fall`; яды и радиация → `poison` (`DMG_NERVEGAS` ×1,5, `DMG_RADIATION` ×0,5); `DMG_SONIC` → `blunt`; остальное → `generic`.

## Стадии

Каждое попадание проходит стадии по порядку; функция `fn(ply, hit)`, вернувшая `false`, завершает попадание.

| Порядок | Стадия | Что делает |
|---|---|---|
| 100 | `localize` | куда входит луч: `hit.structure`, `segment`, `region`, `side` (`organism:Locate`) |
| 200 | `armor` | модуль `armor` |
| 300 | `wound` | `organism:Injure`, отчёт — в `hit.report` |
| 400 | `impulse` | тряска камеры, толчок от взрыва и удара |
| 500 | `notify` | `damage.hit` и история `nc_damage` |

## Попадание

`kind` (вид травмы `organism`), `attacker`, `inflictor`, `type` (DMG_*), `amount` (урон движка), `pos` и `dir` (Vector, `nil` — неизвестно), `force`, `hitgroup`; пули: `ammo` (имя), `distance` (м), `projectile`, `energy` (Дж), `pellet` и `pellets` (номер дробины и их число); падения: `speed`; яды: `toxin`; `lethal`: `cause`. Стадии добавляют своё: `structure`, `segment`, `region`, `side`, `armor`, `absorbed`, `report`.

## Боеприпасы

Тип боеприпаса — один снаряд: масса (г), скорость (м/с у дула), диаметр (мм), проникание (см мягких тканей), `expansion` (раскрытие экспансивной пули), `fragment` (глубина, на которой пуля разрушается, см) и `fragmentFactor`, `range` (м — на этой дистанции скорость падает в e раз), `ap` (бронебойность, 1 — обычная). Дробь — один снаряд на дробину. Энергия — ½·m·v² с учётом дистанции, умноженная на `scale`.

| Боеприпас | Масса, г | Скорость, м/с | Диаметр, мм | Энергия у дула, Дж |
|---|---|---|---|---|
| `Pistol`, `AlyxGun` (9×19) | 8 | 360 | 9 | 518 |
| `357` | 10,2 | 440 | 9,1 | 987 |
| `SMG1` (4,6×30) | 2 | 720 | 4,6 | 518 |
| `AR2` (как 5,56×45) | 4 | 940 | 5,7 | 1767 |
| `Buckshot` (картечина 00) | 3,5 | 400 | 8,4 | 280 |
| `XBowBolt` | 100 | 120 | 10 | 720 |
| `SniperRound` (7,62×51) | 9,7 | 850 | 7,8 | 3504 |
| `AirboatGun` | 30 | 800 | 12,7 | 9600 |
| `StriderMinigun`, `HelicopterGun`, `CombineCannon` | 45 | 900 | 14,5 | 18225 |

Бронебойность `ap` у всех 1, кроме `SMG1` — 1,4 (остроконечная пуля 4,6×30); как её считает броня — в [`armor`](../armor/README.md).

## API (сервер)

- `M:Apply(ply, hit)` — провести попадание через стадии, как будто его нанёс движок (для модулей оружия и взрывов); отчёт `organism` или `nil`.
- `M:AddStage(id, порядок, fn)`, `M:RemoveStage(id)`, `M:Stages()` — стадии.
- `M:RegisterAmmo(имя, def)`, `M:Ammo(имя)`, `M:Projectile(имя, дистанция, урон)` → снаряд и энергия.
- `M:KindOf(ply, dmginfo)` — вид травмы урона; `M:History(n)` — последние попадания.
