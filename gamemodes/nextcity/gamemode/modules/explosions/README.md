# Модуль `explosions` — взрывы

Один API для любых зарядов пакетов: гранат, мин, снарядов, бочек. Ударная волна по приведённому расстоянию бьёт по телам через конвейер `damage`, корпус разлетается осколками `ballistics`, взрыв движка толкает и ломает остальное. Своих взрывчаток в ядре нет (D15).

| | |
|---|---|
| Интерфейс | `explosions` |
| Зависимости | `players`, `organism`, `damage`; необязательно `ballistics` |
| Испускает | `explosions.exploded (pos, attacker, inflictor, charge)` |
| Отвечает | `damage.kind` — `false` игрокам во время взрыва движка (их волна — отдельное попадание) |
| Команды | `nc_explode [заряд кг] [корпус кг] [игрок]` — взрыв там, куда смотришь, или у ног игрока |
| Настройки | `blast` = 1 — множитель волны по телам; `fragments` = 1 — доля осколков, которые летят (0 — без осколков); `maxFragments` = 300 — осколков одного взрыва; `engine` = `true` — взрыв движка (пропы, NPC, стекло, упавшие тела); `effects` = `true` — вспышка со звуком, копоть, тряска экранов |

## Как устроено

1. **Волна.** Пиковое избыточное давление в середине каждого тела по приведённому расстоянию `Z = R / W^(1/3)` (формула Кинни — Грэма для взрыва ТНТ в воздухе). Заряд на земле (мир ближе 12 юнитов под ним) считается в 1,8 раза больше — волна отражается от грунта; за стеной (мир между центром и телом) доходит четверть. Давление становится попаданием `blast` организма через `damage:Inflict`: количество — половина кПа (лёгкие, контузия, отброс); около 500 кПа (250) убивает сразу, от 120 кПа (60) сбивает с ног (`ragdoll`). Дальше `Z = 12` (меньше 8 кПа) волна безвредна.
2. **Осколки.** Корпус распадается на `fragments` осколков (по умолчанию по грамму) и летит снарядами `ballistics` во все стороны равномерно (золотая спираль со случайным поворотом) или в конусе `cone` вокруг `dir` (направленный заряд). Скорость — по Гёрни для заряда и корпуса: `2440 / √(корпус / заряд + 0,6)` м/с. Осколок по умолчанию — стальной кусок своей массы: диаметр, дальность сопротивления воздуха и проникание считаются по массе. Осколки могут попасть и во владельца заряда. Без `ballistics` тело получает ожидаемое для своего размера число осколков (0,5 м² на сферу или конус расстояния), за стеной — ни одного.
3. **Движок.** `util.BlastDamageInfo` с `DMG_BLAST` толкает и ломает пропы, ранит NPC, толкает упавшие тела; игрокам этот урон не наносит травм — ответ `false` на `damage.kind`. Урон в центре — `200·W^(1/3)`, радиус — до `Z = 12`.
4. **Эффекты** — `Explosion` (вспышка и звук) или `WaterSurfaceExplosion` в воде, копоть `Scorch`, тряска экранов в двойном радиусе.

## API (сервер)

- `M:Explode(pos, opts)` → тел задето, осколков выпущено. `opts` (всё необязательно):

| Поле | Что это | По умолчанию |
|---|---|---|
| `attacker`, `inflictor` | кто взорвал и чем (граната) | мир |
| `charge` | кг тротилового эквивалента | 0,2 |
| `casing` | кг металла, который разлетается осколками | 0 |
| `fragments` | число осколков | по грамму корпуса |
| `fragment` | `{ mass г, velocity м/с, diameter мм, penetration см, range м, ap }` — что задано, заменяет расчёт; без `casing` нужны `mass` и `fragments` | доля корпуса, Гёрни, стальной кусок |
| `dir`, `cone` | осколки в конусе `cone` градусов вокруг `dir` | во все стороны |
| `radius`, `damage` | радиус (юниты) и урон в центре взрыва движка | по заряду |
| `filter` | сущность, в которую осколки не попадают | — |
| `ammo` | имя попаданий осколков (`nc_damage`) | — |
| `effects` | `false` — без эффектов | `true` |

- `M.Overpressure(z)` → кПа; `M.FragmentSpeed(заряд, корпус)` → м/с; `M.Chunk(масса г)` → диаметр (мм), дальность (м), проникание (см).

```lua
-- Пакет: граната (`throwables`) взрывается там, где сработал запал.
detonate = function(ent, thrower, pos)
	explosions:Explode(pos, { attacker = thrower, inflictor = ent, charge = 0.06, casing = 0.3, fragments = 250,
		filter = ent })
end
```

## Проверить в реальном GMod

- `nc_explode 0.2 0.2` на разных дистанциях: ранения, падение тел, смерть рядом; укрытие за стеной.
- Нагрузка: 300 осколков — `nc_ballistics`, время `ballistics:fly` в `nc_perf`; несколько взрывов подряд.
- `util.BlastDamageInfo`: пропы разлетаются, стекло бьётся, NPC ранятся, упавшие тела толкает; игрок не получает урона движка.
- Эффект `Explosion` со звуком, копоть, тряска; в воде — `WaterSurfaceExplosion`.
