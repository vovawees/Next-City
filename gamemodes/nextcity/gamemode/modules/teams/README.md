# Модуль `teams` — команды

Палитра до четырёх команд, распределение поровну, счёт команд и блоки правил для раундов. Сами режимы команд не создают: они подключают правило `teams` и получают остальное.

| | |
|---|---|
| Интерфейс | `teams` |
| Зависимости | `players`; необязательно `rounds` (без него нет правил) |
| Слушает | `players.stateChanged`, `net.ready`, `i18n.changed` |
| Испускает | `teams.changed (ply, index, old)` — на сервере; `teams.scores (scores)` — на сервере и на клиенте |
| Сеть | `scores` — счёт команд в игре (пусто вне командной игры) |
| Переводы | `lang/<код>/teams.lua` |

## Палитра

| Индекс | Ключ | Цвет | Точки появления |
|---|---|---|---|
| 1 | `red` | 220, 64, 52 | сторона `a` |
| 2 | `blue` | 52, 120, 220 | сторона `b` |
| 3 | `green` | 64, 170, 72 | любые |
| 4 | `yellow` | 226, 180, 40 | любые |

Команды регистрируются в движке (`team.SetUp`) на обоих концах с названиями на языке этого конца и переименовываются при смене языка. Во время командной игры готовые игроки вне команд — в `TEAM_SPECTATOR`, вне её все в `TEAM_UNASSIGNED`.

## API

- `M:Count()` — сколько команд в игре (0 — нет командной игры), `M:Score(index)`, `M:Of(ply)` — команда игрока из палитры или `nil`, `M:Members(index)`, `M:IsPlayable(index)`, `M:Color(index)`, `M:NameKey(index)` — доступно и на клиенте.
- Сервер: `M:SetCount(count)` — начать командную игру с нулевым счётом (0 — закончить), `M:Assign(ply, index)`, `M:Smallest(count)` — самая маленькая команда (при равенстве — с меньшим индексом), `M:AliveCount(index)`, `M:SetScore(index, score)`, `M:AddScore(index, amount)`, `M:Leader()` — лидер по счёту или `nil` при равенстве.

Изменения счёта за тик уходят клиентам одним сообщением.

## Правила

| Правило | Параметры | Что делает |
|---|---|---|
| `teams` | `teams` = 2 (2..4), `friendlyFire` = `false` | участники — в самую маленькую команду, команды 1 и 2 появляются на своих сторонах, без `friendlyFire` свои не ранят своих |
| `team_elimination` | — | команда без живых и без ожидающих возрождения выбывает; последняя оставшаяся побеждает |
| `team_score` | `scoreLimit` = 50 (0 — без лимита) | убийство противника — очко команде убийцы; лимит — победа, по истечении времени побеждает лидер (равенство — ничья) |

Итоги: `{ reason = "elimination" | "score" | "time", team = индекс }`.

## Клиент

Под таймером раунда — счёт команд в игре их цветами («Красные 12   Синие 9»); строки пересчитываются только при изменении счёта или языка.
