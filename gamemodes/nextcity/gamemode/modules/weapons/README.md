# Модуль `weapons` — огнестрельное оружие

База огнестрельного оружия пакетов. Оружие — данные (калибр, магазин, темп, режимы огня, точность, отдача, обращение), которые регистрирует пакет; база `nc_firearm` исполняет их как скриптовое оружие. Огонь, отдача, разброс, раскачка прицела, прицеливание и перезарядка предсказываются на клиенте стрелка, пули летят физическими снарядами `ballistics` с сервера. Своего оружия в ядре нет (D15).

| | |
|---|---|
| Интерфейс | `weapons` |
| Зависимости | `players`, `organism`, `ammo`; необязательно `ballistics` |
| Испускает | `weapons.fired (owner, weapon, ammoId)` — сервер, каждый выстрел |
| Команды | `nc_weapons` — зарегистрированное оружие: калибр, магазин, темп, режимы, перезарядка (доступна всем игрокам); `nc_give <игрок> <класс> [запас]` — заряженное оружие и патроны в запас движка (по умолчанию два магазина); любое другое скриптовое оружие (ближний бой, руки) — как его выдаёт движок |
| Настройки | `recoil` = 1, `spread` = 1, `sway` = 1 — множители отдачи, разброса и раскачки всего оружия; `sprint` = `true` — на бегу оружие опущено, стрелять и целиться нельзя; `crosshair` = `false` — прицел движка; `ammoCounter` = `false` — счётчик патронов движка |
| Строки | названия `weapons.<класс>` — в `lang/<код>/weapons.lua` пакета; режимы огня `weapons.mode.*` — в ядре |

## Определение оружия

Обязательны только `caliber` и `magazine`, у остальных полей есть значения по умолчанию.

| Поле | Что это | По умолчанию |
|---|---|---|
| `caliber` | подходят патроны этого калибра (`ammo`); `ammo` — тип, которым оружие заряжено при выдаче | первый тип калибра |
| `magazine` | патронов в полном магазине; `chamber` — ещё один в патроннике (закрытый затвор; `false` — открытый затвор, револьвер) | — ; `true` |
| `rpm` | выстрелов в минуту | 600 |
| `modes` | режимы огня по порядку переключения, первый — при выдаче: `"semi"`, `"burst"`, `"auto"`; `burst` — выстрелов в очереди с отсечкой | `{ "semi" }`; 3 |
| `velocity` | множитель начальной скорости патрона — ствол | 1 |
| `accuracy` | MOA, кучность самого ствола | 2 |
| `hipSpread` | градусы разброса от бедра; `moveSpread` — добавка на полной скорости ходьбы, в прыжке — ещё вдвое больше | 3; 2 |
| `sway` | множитель раскачки прицела: вес и баланс | 1 |
| `recoil` | `up` — градусов подъёма взгляда за выстрел (1), `side` — в сторону (0,3), `punch` — доля толчка камеры (0,5), `bloom` — градусов разброса за выстрел (0,25), `recovery` — 1/с, с которой разброс спадает (4), `kick` — юнитов отдачи viewmodel назад (1) | |
| `aimTime` | с, чтобы поднять прицел; `sights` — `{ pos = Vector(вправо, вперёд, вверх), ang = Angle, fov = доля поля зрения }` viewmodel в прицеле | 0,3; `fov` 0,8 |
| `draw` | с, чтобы достать | 0,6 |
| `reloadMode` | `"magazine"` или `"single"` — по одному патрону (трубчатый магазин, барабан) | `"magazine"` |
| `reload` | с: смена магазина или один патрон при `single`; `reloadEmpty` — пустого оружия (ещё и затвор); `reloadStart`, `reloadEnd` — до первого патрона и после последнего при `single` | 2,5; `reload`; 0 |
| `hands` | 2 или 1: одноручное оружие в одной руке не хуже | 2 |
| `sounds` | `{ fire, empty, reload, reloadEmpty, draw, mode }` — имена звуков | `empty` — `Weapon_Pistol.Empty` |
| `anims` | `ACT_VM_*` для `{ fire, fireLast, empty, draw, reload, reloadEmpty, reloadStart, reloadInsert, reloadEnd }` | стандартные `ACT_VM_*` |
| `holdType`, `viewModel`, `worldModel`, `viewModelFOV`, `viewModelFlip`, `useHands`, `slot`, `slotPos`, `weight` | как у оружия движка | `holdType`: `"ar2"`, одноручное — `"pistol"` |
| `name` | ключ перевода названия | `"weapons.<класс>"` |

Регистрировать — в `Init` модуля пакета (`requires = { "ammo", "weapons" }`), на обоих realm в одном порядке, после патронов. Ошибка в определении — `error` с причиной: `weapons: Register('my_ak74'): caliber 5.45x39 has no rounds (ammo:Register them first)`.

```lua
-- lua/nextcity/modules/my_guns/module.lua
return { id = "my_guns", requires = { "ammo", "weapons" }, files = { sh = { "sh_my_guns.lua" } } }

-- lua/nextcity/modules/my_guns/sh_my_guns.lua
local M = NC.Module("my_guns")

function M:Init(ctx)
	local ammo, weapons = ctx:Require("ammo"), ctx:Require("weapons")
	ammo:Register("545_7n6", { caliber = "5.45x39", mass = 3.4, velocity = 880, diameter = 5.6, penetration = 70,
		range = 900, ap = 1.3 })
	weapons:Register("my_ak74", { caliber = "5.45x39", magazine = 30, rpm = 650, modes = { "semi", "auto" },
		reload = 2.4, reloadEmpty = 3.1, recoil = { up = 0.9, side = 0.35 },
		viewModel = "models/weapons/c_smg1.mdl", worldModel = "models/weapons/w_smg1.mdl",
		sights = { pos = Vector(-6.4, -2, 1), fov = 0.75 }, sounds = { fire = "Weapon_SMG1.Single" } })
end
```

Название — в `lang/ru/weapons.lua` пакета: `return { my_ak74 = "АК-74" }`.

## Как устроено

1. **Класс.** `Register` копирует определение, дополняет значения по умолчанию и регистрирует скриптовое оружие `class` на базе `nc_firearm`: `Primary.ClipSize` — магазин плюс патронник, тип боеприпаса — патрон по умолчанию, слот — 1 у одноручного, 2 у двуручного. Повторная регистрация (автообновление пакета) заменяет определение и у оружия, которое уже в руках.
2. **Предсказание.** Состояние оружия — предсказываемые NetworkVars: состояние (`idle`, `draw`, `reload`, `starting` → `loading` → `finishing` у перезарядки по патрону) и время его конца, режим огня, остаток очереди, удержание спуска, разогрев (bloom), прицеливание, тип патронов в оружии и в перезарядке. Клиент стрелка исполняет тот же код, что и сервер, случайность — `util.SharedRandom` от номера команды, эффекты клиента — при `IsFirstTimePredicted`. Состояния, которые закончились, пока оружие не думало, заканчиваются по очереди (`Think`, `PrimaryAttack`, `Reload`).
3. **Огонь.** Движок вызывает `PrimaryAttack`, пока атака зажата (`Automatic` у всех), дисциплина спуска — в базе: `semi` стреляет снова после отпускания, `burst` — `burst` выстрелов за одно нажатие (отпускание обрывает очередь), `auto` — пока зажато. Интервал — `60 / rpm`. Пустое оружие щёлкает раз за нажатие. `E` + `R` (use + reload) переключает режим, клиент показывает название режима.
4. **Выстрел** идёт по взгляду с толчком камеры и раскачкой прицела, в конусе разброса: `accuracy / 60` + `hipSpread × (1 − прицеливание)` + `moveSpread × скорость / скорость ходьбы` + `bloom × разогрев`, в прыжке ещё `2 × moveSpread`; присед ×0,8; двуручное в одной руке ×2. С `ballistics` сервер выпускает патрон `ballistics:Fire` (оружие — инфликтор, разброс прицела, множитель скорости ствола, компенсация задержки), без него — пули движка `FireBullets` на обоих realm (урон = энергия патрона × `velocity`² × 0,04, клиент стрелка рисует попадания). Сервер испускает `weapons.fired`.
5. **Отдача.** Толчок камеры (`ViewPunch`) на обоих realm и подъём взгляда (`SetEyeAngles`) там, где делаются углы взгляда: на клиенте стрелка (первое предсказание), на сервере — у ботов и в одиночной игре. Сторона — `SharedRandom`, присед ×0,8, `recoilMul` организма.
6. **Тело.** Возможности организма: без рабочей руки или без сознания нельзя стрелять, целиться и перезаряжаться; двуручное в одной руке — вдвое больше разброс и раскачка; `aimSway` (боль, усталость, раненые руки, шок, контузия, сознание) раскачивает прицел, `recoilMul` (руки, боль, усталость) усиливает отдачу. Раскачка — плавные синусы времени в фазе игрока (одинаковые на всех realm): дыхание и тремор рук, меньше в прицеле и в приседе. На бегу (`sprint`: клавиша бега, на земле, быстрее ходьбы) оружие опущено.
7. **Прицеливание** — пока зажата атака 2: прицел поднимается за `aimTime`, viewmodel переходит к `sights.pos/ang`, поле зрения сужается до `sights.fov`, мышь замедляется вместе с ним, раскачка и покачивание движка затихают. Viewmodel поворачивается вокруг глаз вместе с раскачкой, поэтому прицел показывает, куда уйдёт пуля.
8. **Перезарядка** (`R`) — из источника патронов, по умолчанию запас движка игрока (`GiveAmmo`), предсказываемый клиентом. `magazine`: через `reload` (пустое — через `reloadEmpty`) оружие пополняется до магазина, плюс патрон в патроннике, если он там был. `single`: `reloadStart`, затем по патрону за `reload`, затем `reloadEnd`; атака останавливает перезарядку после патрона в руке. Пока в оружии есть патроны, перезаряжается тем же типом; пустое — первым типом калибра, который есть в запасе. Убрать оружие — отменить перезарядку (заряженные патроны остаются).

## API

Общее:

- `M:Register(class, def)` → определение (копия с умолчаниями); заменяет существующее.
- `M:Get(class)` → определение (не изменять) или `nil`; `M:All()` → классы по порядку регистрации (новый список); `M:IsFirearm(weapon)`; `M:Name(class)` → переведённое название.
- `M:SetAmmoSource(source)` — откуда перезарядка берёт патроны: `source.Count(ply, weapon, ammoId)` → число и `source.Take(ply, weapon, ammoId, count)` → взято, одинаково на обоих realm (предсказание); `nil` — снова запас движка (`M.ENGINE_AMMO`). Так инвентарь (M6) подключит магазины и подсумки. `M:CountAmmo`, `M:TakeAmmo`, `M:ReloadAmmo(ply, weapon)` → тип следующей перезарядки или `nil`.
- `M:Sprinting(ply)`; `M.STATES` — номера состояний.
- Методы оружия: `Def()`, `FireMode()`, `LoadedAmmo()`, `AimFraction(now)`, `HeatAt(now)`, `Spread(owner, now)`, `SwayAt(owner, now)`, `CanFire(owner)`, `CanAim(owner)`, `StartReload()`, `SwitchMode()`.

Сервер:

- `M:Give(ply, class, opts)` → оружие или `nil` и причина. Выдаёт заряженное оружие (или перезаряжает то, что уже есть). `opts`: `ammo` — другой тип калибра, `empty` — без патронов, `reserve` — патронов этого типа в запас.

## Проверить в реальном GMod

- Регистрация из модуля пакета: `nc_give`, `ply:Give`, выбор слота; автообновление файла пакета обновляет оружие в руках.
- Анимации viewmodel моделей `c_*`: `draw`, `reload`, `reloadEmpty`, `reloadStart/Insert/End` и растяжение `SetPlaybackRate` на их время; руки (`UseHands`).
- Предсказание с пингом 100–200 мс: нет двойных выстрелов и звуков, счётчик патронов и перезарядка не дёргаются, отсечка очереди и одиночный огонь срабатывают ровно.
- Подъём взгляда от отдачи (`SetEyeAngles` на клиенте) с пингом и у ботов; `ViewPunch` не накапливается.
- Смещения `sights` и поле зрения у разных моделей; раскачка viewmodel совпадает с попаданиями; бег опускает оружие.
- Без `ballistics`: пули движка, их урон и следы у стрелка.
