# Модуль `ballistics` — баллистика

Физические снаряды: пули и осколки летят по-настоящему — с сопротивлением воздуха, гравитацией и водой, — пробивают преграды, рикошетят и попадают в тела через конвейер `damage`. Один менеджер на сервере: снаряды живут в массивах (без сущности на пулю), один цикл за тик. Своих патронов нет — снаряд берётся из типа боеприпаса модуля `ammo` (D15).

| | |
|---|---|
| Интерфейс | `ballistics` |
| Зависимости | `organism`, `damage`, `ammo` |
| Испускает | `ballistics.impact (owner, ent, pos, dir, energy, outcome)` — каждый контакт; `outcome`: `"body"`, `"through"`, `"ricochet"`, `"stop"`, `"water"` |
| Команды | `nc_ballistics` — снарядов в полёте, выпущено, контактов |
| Настройки | `maxProjectiles` = 1024 — в полёте одновременно (новый заменяет самый старый); `lifetime` = 4 с; `minEnergy` = 5 Дж — медленнее снаряд останавливается; `gravity` = 1, `penetration` = 1 (0 — не пробивает), `ricochets` = 2 (0 — без рикошетов), `scale` = 1 (энергия попаданий по телам), `push` = 1 — множители; `lagCompensation` = `true`, `maxCatchUp` = 0,25 с; `entityDamage` = 0,04 — урон движка на Дж для пропов, NPC, стекла; `effects` = `true` |

## Как устроено

1. **Полёт.** Квадратичное сопротивление воздуха: скорость падает в e раз на дистанции `range` патрона, `v(x) = v0·e^(-x/range)` — тот же закон, что у `damage` для пуль движка, поэтому `ammo:At` даёт ровно энергию на дистанции. Шаг считается в замкнутом виде, без накопления ошибки. Гравитация настоящая (9,81 м/с²). В воде (`util.PointContents`) сопротивление как у воздуха в 800 раз плотнее: пистолетная пуля теряет почти всю скорость за метр.
2. **Тела.** Живой игрок или тело, в котором он лежит (`organism:PlayerOf`, регдолл упавшего): попадание `damage:Inflict` — правила раунда, броня, организм. Чего тело не забрало (`hit.energy` минус энергия отчёта организма), с тем пуля летит дальше и может попасть в следующего; броня, остановившая пулю (`hit.stopped`), останавливает и снаряд. Тело не попадается дважды. Упавшее тело толкает импульс, который оно забрало. Мёртвое тело или игрок вне урона по правилам: тело — 25 см плоти на пути, живой — как будто его нет. NPC и некстботы — урон движка и 25 см плоти.
3. **Материалы.** Ниже угла рикошета материала (градусы к поверхности) снаряд отскакивает — тем вероятнее, чем площе; теряет часть скорости, летит площе, после рикошета может попасть в своего стрелка. Иначе пробивает настолько, насколько позволяет угроза: глубина, см = энергия × √(9/диаметр) × `ap` / сопротивление материала (Дж/см для 9 мм). Толщину находят обратные трассы изнутри (до 64 юнитов), энергия падает пропорционально пройденной толщине, на выходе небольшое отклонение. Грунт дисплейсментов не пробивается. Пропы, NPC, стекло получают урон движка (`DMG_BULLET`, тип боеприпаса, сила импульса).
4. **Компенсация задержки.** Выстрел в команде самого стрелка (`GetPredictionPlayer()` — он, например в `PrimaryAttack` оружия): часть полёта, которую скрывает его пинг (не больше `maxCatchUp`), пролетает сразу под `ply:LagCompensation(true)` — пуля попадает туда, куда стрелок видел цель. Остальное — обычным циклом в `Tick`; выстрел вне команды (таймер, турель) летит с ближайшего тика.
5. **Эффекты** (на всех клиентов): `Impact` (декаль и звук материала, вход и выход), `BloodImpact` и декаль крови за телом, `gunshotsplash` на воде.

## Материалы

`M.MATERIALS[MAT_*] = { resistance = Дж/см, ricochet = градусы }`; неизвестный — `M.DEFAULT_MATERIAL` (300, 10°). Поверхность воды — рикошет ниже `M.WATER_RICOCHET` = 7°.

| Материал | Дж/см | Рикошет | | Материал | Дж/см | Рикошет |
|---|---|---|---|---|---|---|
| металл, вентиляция, решётка | 3500 | 20–25° | | стекло | 60 | 10° |
| бетон | 400 | 15° | | дерево, грязь, трава | 50 | 5–6° |
| плитка | 300 | 15° | | пластик | 40 | 8° |
| компьютер | 600 | 15° | | снег | 20 | 5° |
| песок | 70 | 5° | | листва | 3 | — |
| плоть | 10 | — | | warpshield | ∞ | — |

Пример: 9×19 (518 Дж) проходит 10 см дерева и 1,3 см бетона; 5,45×39 (1316 Дж, `ap` 1,3) — 33 см дерева и 4 см бетона. Пакет меняет материал: `ballistics:SetMaterial(MAT_WOOD, { resistance = 40, ricochet = 5 })`.

## API (сервер)

- `M:Fire(owner, origin, dir, ammoId, opts)` → число снарядов. Выстрел патроном типа `ammoId`: его дробины летят снарядами в конусе `spread` патрона. `opts`: `inflictor` (оружие), `spread` (градусы: разброс прицела, общий для дробин), `velocity` (множитель начальной скорости — ствол), `filter` (сущность, в которую выстрел не попадёт, например машина), `lagCompensate = false` — без компенсации. Неизвестный тип — `error`.
- `M:Launch(owner, origin, velocity, projectile, opts)` — один снаряд (осколок): `velocity` — вектор, юнит/с; `projectile` — `{ mass, diameter, penetration, range, ... }` как у патрона; `opts`: `inflictor`, `kind` (`"fragment"` по умолчанию — вид травмы), `ammo` (имя для попаданий), `filter`, `hitsOwner = true` — может попасть и во владельца (осколки его же гранаты).
- `M:Count()`, `M:Clear()`, `M:SetMaterial(mat, def)`.

Попадание по телу: `kind`, `attacker`, `inflictor`, `type = DMG_BULLET`, `pos`, `dir`, `force`, `hitgroup` (у регдолла `HITGROUP_GENERIC`), `ammo`, `distance` (м пролёта), `projectile` (скорость и проникающая способность в тканях на месте), `energy`, `pellet`/`pellets`.

## Проверить в реальном GMod

- Трассы против мира, пропов, стекла (`func_breakable_surf`) и хитбоксов: обратная трасса из толщи находит выход, `StartSolid` внутри браша и пропа, `DispFlags` у дисплейсментов.
- Компенсация задержки с ботами и с пингом 100–200 мс: попадания по бегущему совпадают с прицелом.
- Нагрузка: сотни дробин (дробовики, автоматный огонь) — `nc_ballistics`, время задачи `ballistics:fly` в `nc_perf`.
- Эффекты `Impact` на входе и выходе, кровь, всплески; звуки и декали материалов.
