# Модуль `ammo` — боеприпасы

Реестр патронов пакетов: калибры, снаряды и типы боеприпасов движка. В ядре патронов нет — их регистрируют модули контента (D15).

| | |
|---|---|
| Интерфейс | `ammo` |
| Зависимости | `damage` |
| Команды | `nc_ammo [калибр]` — зарегистрированные патроны: масса, скорость, энергия на 0, 100 и 300 м |
| Настройки | `maxCarry` = 9999 — сколько патронов типа игрок носит в запасе движка, если тип не задал своё |
| Строки | названия `ammo.<id>` — в `lang/` пакета |

## Тип боеприпаса

Один патрон. `id` — он же имя типа боеприпаса движка (оружие, `GiveAmmo`, HUD).

| Поле | Что это |
|---|---|
| `caliber` | калибр: патроны одного калибра подходят одному оружию (`"9x19"`, `"12/70"`) |
| `mass` | г, одного снаряда |
| `velocity` | м/с у дула эталонного ствола |
| `diameter` | мм |
| `penetration` | см мягких тканей |
| `range` | м: сопротивление воздуха снижает скорость в e раз на этой дистанции |
| `expansion` | насколько раскрывается экспансивная пуля (необязательно) |
| `fragment`, `fragmentFactor` | глубина, см, на которой пуля разрушается, и во сколько раз она потом теряет энергию быстрее (необязательно) |
| `ap` | бронебойность: насколько лучше снаряд пробивает броню и преграды, по умолчанию 1 |
| `pellets` | снарядов в патроне (дробь), по умолчанию 1 |
| `spread` | градусы: конус дробин, по умолчанию 0 |
| `maxCarry` | сколько патронов носит игрок, по умолчанию `config.maxCarry` |

Регистрировать — в `Init` модуля пакета (`requires = { "ammo" }`), на обоих realm в одном порядке: типы боеприпасов движка должны появиться до начала игры. После автообновления движок сохраняет уже созданные типы.

```lua
function M:Init(ctx)
	local ammo = ctx:Require("ammo")
	ammo:Register("9x19_fmj", { caliber = "9x19", mass = 8, velocity = 360, diameter = 9, penetration = 60,
		range = 540 })
	ammo:Register("12g_buck", { caliber = "12/70", mass = 3.5, velocity = 400, diameter = 8.4, penetration = 30,
		range = 100, pellets = 9, spread = 1.5 })
end
```

## API

Общее:

- `M:Register(id, def)` → тип; заменяет существующий (и переносит его в новый калибр). Ошибка в определении — `error` с причиной.
- `M:Get(id)` → тип (не изменять) или `nil`; `M:OfCaliber(калибр)`, `M:All()` → id по порядку регистрации (новый список).
- `M:At(id, дистанция)` → скорость (м/с) и энергия (Дж) снаряда после полёта (только сопротивление воздуха).

Сервер: каждый тип попадает в `damage:RegisterAmmo`, поэтому пули движка этого типа (`FireBullets` чужого оружия) ранят как его снаряд.

## Проверить в реальном GMod

- Типы появляются у сервера и клиента с одинаковыми id (`game.GetAmmoID`), `ply:GiveAmmo(30, "9x19_fmj")` работает, HUD движка показывает запас.
- `nc_ammo` выводит таблицу; автообновление файла пакета не создаёт дубликатов типов.
