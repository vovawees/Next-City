# Модуль `identity` — личность персонажа

Имя и пол персонажа каждого игрока в его профиле (раздел `identity` модуля [`profiles`](../profiles/README.md)). Новичок получает случайного персонажа на своём языке, меняет его во вкладке «Персонаж» меню F1 или командой `nc_rpname`, после смены ждёт кулдаун. Остальные видят имя персонажа вместо ника только там, где режим включает личности (вопрос `identity.enabled`; город отвечает «да»).

| | |
|---|---|
| Интерфейс | `identity` (оба realm) |
| Зависимости | `players`, `profiles`; необязательные: `storage` (реестр занятых имён и имена прежнего города), `notices` (что вышло из смены), `menu` (вкладка «Персонаж») |
| Слушает | `profiles.loaded`, `profiles.leaving`, `players.ready`, `players.stateChanged`, `rounds.phase`; отвечает на `players.name` (приоритет 10) |
| Спрашивает | `identity.enabled (ply)` → `true`: другие видят персонажа; `identity.canChange (ply, name, gender)` → `false`: сейчас менять нельзя |
| Испускает | `identity.changed (ply, name, gender, oldName, oldGender)` |
| Компоненты | `identity` (всем, 4/с): `name`, `gender` — пока режим включает личности; `character` (владельцу, 2/с): `name`, `gender`, `random`, `ready` |
| Сеть | `change` (клиент → сервер, 1/с, запас 3): `name`, `gender` |
| Команды | `nc_rpname [имя]`, `nc_gender [male \| female]` (всем), `nc_setname <игрок> <имя>` (админ) |
| Настройки | `random` = `true`, `minLength` = 2, `maxLength` = 32, `minWords` = 1, `maxWords` = 4, `cooldown` = 1800 с, `unique` = `true`, `registry` = `"identity"`, `refresh` = 1 с |

## Персонаж

```lua
-- раздел identity профиля
{ name = "Анна Каренина", gender = "female", random = false, changed = 1700000000 }
```

- **Новичок** (в профиле нет имени) готов к игре — получает случайный пол и имя из списков своего языка (`ru` — русские имена и фамилии в нужном роде, остальные языки — английские). Занятое имя пробуется до 20 раз, потом берётся двойная фамилия. `random = false` в настройках: имени нет, пока игрок не выберет, другие видят ник.
- **Случайное имя следует за полом**: пока игрок не выбрал своё, смена пола даёт новое случайное имя нужного рода и не запускает кулдаун.
- **Своя смена** имени или пола ставит `changed`; следующая — через `cooldown` секунд (первая своя смена — сразу). Админ (`nc_setname`) меняет без кулдауна и вопроса, кулдаун игрока не трогает.
- **Правила имени**: пробелы по краям убираются, внутри — по одному; `minLength`..`maxLength` символов (не больше 96 байт — 32 кириллические буквы помещаются); буквы любого алфавита, пробел, `'`, `-`, `.`; каждое слово с буквы; `minWords`..`maxWords` слов (2 — имя и фамилия).
- **Уникальность** (`unique`): без учёта регистра (латиница и кириллица) — среди игроков на сервере и в реестре занятых имён (namespace `registry` в `storage`: имя → ключ профиля). Имена ботов и сервера без `storage` заняты только на сессию. Новое имя освобождает старое.
- **Имена прежнего города** (namespace `city` до M8) переходят в профиль при первом заходе и удаляются оттуда; негодные просто удаляются.

## Где видно

Пока режим отвечает `true` на `identity.enabled (ply)`, у игрока есть компонент `identity`, и `players:Name(ply)` — имя персонажа на сервере и у всех клиентов (подпись над игроком, строки чата, уведомления модулей). Ответ проверяется каждые `refresh` секунд, на каждой фазе раунда, когда игрок готов и когда меняется его состояние. Ответы режимов на `players.name` (псевдонимы Homicide) побеждают персонажа.

```lua
-- в Setup режима (раунд снимает ответ сам)
round:On("identity.enabled", function(ply)
	return true
end)
```

## API

```lua
local identity = ctx:Require("identity")        -- в манифесте: optional = { "identity" }
identity:Name(ply); identity:Gender(ply)         -- персонаж, пока его видят другие, или nil (оба realm)
identity:IsShown(ply)
identity:Character(ply)                          -- сервер: { name, gender, random, changed } (только читать)
identity:Change(ply, "Анна Каренина", "female")  -- true или false, причина[, секунды]: loading, gender, same,
                                                 -- short, long, chars, words, taken, cooldown, denied
identity:Change(ply, nil, "male", true)          -- nil — оставить как есть; force — админ: без кулдауна
identity:Request(ply, name, gender)              -- смена от игрока: уведомление о том, что вышло
identity:Wait(ply)                               -- секунд до следующей смены (0 — можно)
identity:IsTaken("алиса вэнс", ply)              -- занято ли имя кем-то другим
identity:NameProblem(name)                       -- short, long, chars, words или nil
identity:RandomName("female", "ru", taken)       -- имя из списков; taken(name) → true пропускает
identity:AddNames("ru", { male = {...}, female = {...}, last = {...}, lastFemale = {...} })
identity:Character()                             -- клиент: свой { name, gender, random, ready }
identity:Ask(name, gender)                       -- клиент: попросить смену (вкладка «Персонаж»)
identity.Fold("АЛИСА"); identity.Length("Алиса"); identity.CleanName("  a  b ")
```

Пакеты добавляют имена (`AddNames`) в `Init` на обоих realm: женские фамилии идут парой к фамилиям по позиции, без них женская форма совпадает.

## Вкладка «Персонаж»

Вторая вкладка меню F1 (после «Профиля»): видят ли другие персонажа сейчас, поле имени с кнопкой «Случайное имя» (по выбранному полу и языку игрока), кнопки пола, «Сохранить персонажа», сколько ждать до следующей смены, правила имени и кулдаун. В меню города (F4) на вкладке профессий — текущее имя и кнопка, открывающая эту вкладку.

## Проверить в реальном GMod

- Новичок с `gmod_language ru` и `en`: случайные имена на своём языке, раздел `identity` в `data/nextcity/profiles/<steamid64>.json`, реестр `data/nextcity/identity.json`.
- Город: имя персонажа над игроком, в уведомлениях о профессиях и розыске; Deathmatch — ник; Homicide — псевдонимы.
- Вкладка «Персонаж»: случайное имя, смена пола, сохранение, кулдаун после смены; `nc_rpname`, `nc_gender`, `nc_setname` у игрока и админа.
- Перенос имён города: `data/nextcity/city.json` прежней версии пустеет после заходов игроков.
