# Модуль `example` — шаблон

Минимальный модуль, на котором виден весь контракт: манифест, файлы по realm, жизненный цикл, подписки и задачи через `ctx`, сетевые сообщения, компоненты и переводы. По умолчанию выключен: чтобы включить, уберите `example = true` из `modules.disabled` в `config.lua`.

| | |
|---|---|
| Интерфейс | `example` |
| Зависимости | нет |
| Слушает | `net.ready` (оба realm), `i18n.changed` (клиент) |
| Сеть | `state` сервер → клиент (счётчик), `wave` клиент → сервер (не чаще 1/с, до 3 подряд) |
| Компоненты | `profile` игрока (`waves`, `mood`), реплицируется всем 4 раза в секунду |
| Задачи | `example:heartbeat` каждые `interval` секунд (сервер) |
| Настройки | `interval` = 5 |
| Переводы | `lang/en/example.lua`, `lang/ru/example.lua` (ключ `example.greeting`) |
| API | `M:Greeting(ply)` — приветствие на языке игрока |

## Как сделать свой модуль

1. Скопируйте папку в `modules/<id>/`; `id` в `module.lua` должен совпадать с именем папки.
2. Укажите `provides`, `requires`, `optional` и файлы по realm (`sh`, `sv`, `cl`).
3. Каждый файл начинается с `local M = NC.Module("<id>")`, всё остальное — `local`.
4. Подписки, задачи и таймеры — только через `ctx:On`, `ctx:Every`, `ctx:After`: они снимаются автоматически при остановке.
5. Сетевые сообщения объявляются в секции `net` манифеста со схемой полей; обработчики — `ctx.net:Receive`, отправка — `ctx.net:Send` / `Broadcast` / `SendToServer`. Полное состояние игроку отправляется по событию `net.ready`.
6. Данные сущностей (здоровье, инвентарь, профиль) — секция `components` манифеста: `ctx.components.<имя>:Add(ent)`, `:Set(ent, "поле", значение)`, `:Get(ent)`. Платформа удаляет данные вместе с сущностью и отправляет клиентам только изменённые поля (`replicate = "all"` или `"owner"`); на клиенте это зеркало только для чтения с `:OnChange(...)`.
7. Тексты интерфейса — ключи переводов: добавьте `lang/en/<id>.lua` и `lang/ru/<id>.lua` и вызывайте `ctx.i18n:T("<id>.<ключ>", params)`.
8. Проверьте: `nc_modules` в консоли сервера и `luajit tests/run.lua`.
