# Модуль `throwables` — метательное

База метательного оружия пакетов: гранат, дымовых, светошумовых, бутылок. Оружие — это данные: предмет, его масса, энергия броска, запал или ударный взрыватель и то, что происходит при срабатывании (функция пакета, например `explosions:Explode`). Своего метательного в ядре нет (D15).

| | |
|---|---|
| Интерфейс | `throwables` |
| Зависимости | `organism` |
| Испускает | `throwables.thrown (owner, ent, class)` — предмет появился в мире (бросок, выпал из руки, сработал в руке, `Launch`); `throwables.detonated (ent, class, thrower, pos)` — сервер |
| Команды | `nc_throwables` — зарегистрированное метательное |
| Настройки | `energy` = 1 — множитель энергии каждого броска; `lob` = 0,3 — доля энергии броска снизу (атака 2); `impactSpeed` = 150 юнитов/с — удар, от которого срабатывает ударный взрыватель; `maxLive` = 64 — живых предметов не больше, самые старые сверх этого гаснут без срабатывания |

## Определение

`throwables:Register(class, def)` в `Init` модуля пакета (на обоих realm, в одном порядке) создаёт скриптовое оружие `class` на базе `nc_throwable` и тип патронов `class` — сколько таких предметов у игрока.

| Поле | Что это | По умолчанию |
|---|---|---|
| `model` | модель оружия и брошенного предмета | обязательно |
| `mass` | кг | 0,4 |
| `energy` | Дж полного броска сверху | 60 |
| `fuse` | с от отлёта скобы до срабатывания | `nil` — без запала |
| `impact`, `arm` | срабатывает от первого удара не слабее `impactSpeed`, но не раньше `arm` с после броска | `false`, 0 |
| `detonate` | `function(ent, thrower, pos, def)` сервера — что делает срабатывание; если предмет разбился об этот удар, `ent` уже недействителен — берите `pos` | — |
| `remove` | убрать предмет после срабатывания | `true` |
| `pull`, `throwTime`, `draw` | с на чеку (одной рукой вдвое дольше), на бросок, на доставание следующего | 0,5 |
| `count`, `max` | сколько приходит с оружием и сколько можно нести | 1, 3 |
| `stamina` | доля выносливости на бросок | 0,03 |
| `entity` | класс брошенного предмета (например, свой SENT пакета) | `prop_physics` |
| `anims` | `{ pull, throw, lob }` — ACT_VM_* | `ACT_VM_PULLPIN`, `ACT_VM_THROW` |
| `sounds` | `{ draw, pin, spoon, throw, bounce }` — имена звуков | — |
| `holdType`, `viewModel`, `viewModelFOV`, `viewModelFlip`, `useHands`, `slot`, `slotPos`, `weight` | как в движке | `grenade`, слот 4 |
| `name` | ключ перевода имени | `throwables.<class>` |

## Как устроено

1. **Чека.** Нажатие атаки (бросок сверху) или атаки 2 (снизу) выдёргивает чеку за `pull` с. Без сознания или без рабочей руки чеку не выдернуть. Состояние (`Step`, `Throw`, `StepTime`, `Fuse`) — предсказываемые NetworkVars: клиент бросающего проигрывает то же, что сервер.
2. **Бросок** — когда клавишу отпустили (сразу, как только чека вышла). Скорость — из энергии, `v = √(2E/m)`: снизу — доля `lob`, без сил — 60%; к ней прибавляется скорость самого игрока. Предмет — физический проп, летит из руки (перед глазами, правее и ниже), бросающий с ним не сталкивается. Бросок тратит один предмет; когда их не осталось, оружие пропадает.
3. **Запал.** Скоба отлетает при броске — или раньше, клавишей перезарядки, пока чека выдернута («подготовка»): тогда запал идёт в руке, и не брошенное вовремя срабатывает в руке.
4. **Убрать оружие** с выдернутой чекой — чека возвращается на место; если запал уже идёт, предмет выпадает из руки.
5. **Ударный взрыватель** — первый удар не слабее `impactSpeed` через `arm` с после броска. Срабатывание — на следующем тике: в обработчике столкновения ничего не удаляют. Разбился об этот удар (бутылка) — срабатывает там, где разбился; удалённый иначе предмет исчезает без срабатывания.
6. **Срабатывание** вызывает `def.detonate` пакета (ошибка пишется в журнал, предмет срабатывает всё равно), испускает `throwables.detonated` и убирает предмет. Отскоки звучат (`sounds.bounce`) не чаще раза в 0,2 с.

## API

- `M:Register(class, def)` → определение; `M:Get(class)`, `M:All()`, `M:Name(class)`; `M.Speed(energy, mass)` → юнитов/с.
- Сервер: `M:Launch(owner, class, opts)` — живой предмет без оружия (`opts.pos`, `opts.velocity`, `opts.fuse` — время срабатывания по `CurTime()`); `M:Detonate(ent)`, `M:IsLive(ent)`, `M:Thrower(ent)`.

```lua
-- Пакет: осколочная граната с запалом 3,5 с.
throwables:Register("frag", { model = "models/weapons/w_grenade.mdl", viewModel = "models/weapons/c_grenade.mdl",
	useHands = true, mass = 0.6, fuse = 3.5, max = 2,
	detonate = function(ent, thrower, pos)
		explosions:Explode(pos, { attacker = thrower, inflictor = ent, charge = 0.06, casing = 0.3, filter = ent })
	end })
```

## Проверить в реальном GMod

- Модели `c_grenade` с руками: анимации чеки, броска сверху и снизу, доставания; предсказание без дрожи и двойных бросков при лаге (`net_fakelag`).
- Дальность и скорость броска 0,4–1 кг, бросок на бегу; бросок у стены не проходит сквозь неё.
- Подготовка клавишей перезарядки, срабатывание в руке, смена оружия с выдернутой чекой и с идущим запалом.
- Ударный взрыватель на бутылке, которая бьётся (`glassbottle01a`); отскоки гранаты, звук не чаще 0,2 с; `maxLive`.
