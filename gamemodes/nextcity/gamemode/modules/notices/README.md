# Модуль `notices` — уведомления

Короткие сообщения игрокам на их языке. Сервер отправляет ключ перевода и параметры, каждый клиент переводит сам: всплывающие строки справа вверху и, по желанию, строка в чате.

| | |
|---|---|
| Интерфейс | `notices` |
| Зависимости | — |
| Слушает | `gm.HUDPaint`, `i18n.changed` (клиент) |
| Испускает | `notices.shown (key, params, kind, text)` — на клиенте |
| Сеть | `notice` — сервер → клиент: ключ, вид, флаг чата, до 8 параметров |
| Настройки | `duration` = 6 с на экране, `max` = 5 строк одновременно |

## API

```lua
local notices = ctx:Require("notices")              -- в манифесте: optional = { "notices" }
notices:Send(ply, "inventory.full", nil, "warn")
notices:Send({ a, b }, "medical.done", { target = ply:Nick(), item = { key = "items.bandage.name" } }, "good")
notices:Broadcast("mode_homicide.start", nil, "info", { chat = true })
```

- `kind`: `info` (по умолчанию), `good`, `warn`, `bad` — цвет строки.
- Параметры: строка, число (формы множественного числа: `{ count = 3 }`) или `{ key = "..." }` — переводится на стороне клиента.
- Значения обрезаются до 128 байт без разрыва символов UTF-8; ключ без перевода показывается как текст.
- На клиенте `notices:Show(key, params, kind, opts)` — те же уведомления от клиентских модулей; `notices:Active()` — строки на экране.

Тексты переводятся при получении и заново при смене языка, а не каждый кадр.
